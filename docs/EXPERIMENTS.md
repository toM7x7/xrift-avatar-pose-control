# ride姿勢の実験指針

他姿勢への探索は[18候補の大量SIM](experiments/pose-patterns-2026-10-25.md)。`/patterns.html`で実VRMを選び、540条件の一次screenから代表の連続検査と目視へ進む。新候補を採用済みN02と混同しない。自作骨格の再現入口は`npm run replay:patterns`。

再現する基準は採用済みの[N02 通常飛行1.0.0](specs/N02_NORMAL_FLIGHT_V1.md)。`npm run replay:n02`の入力正本はJSONで、デモと共有する。新しい調整はこの基準との差分として記録する。以下は採用までの実験履歴。

最新は[傾く雲と胸腰脚の追従](experiments/n02-tilted-ride-2026-10-25.md)。上下pitch・左右bankの支持面で足裏を合わせ、通常の頭の世界向きを保つ。傾斜ON/OFF・実VRM96枚・自作14条件と旧回帰を分け、法線方向の靴底とCOM高で受け入れる。

最新は[上下移動と胸腰脚の連動](experiments/n02-vertical-ride-2026-10-25.md)。企画から鉛直運動へ進み、実VRM2体の7状態×3方向を観察した。自作ブラウザ14条件・既存の回帰と区別し、無効だった比較元も明記。足場のbank・宙返り・実XRiftへの接続は次段階です。

上下・立体旋回へ進める次段階は[3D筋斗雲飛行の姿勢・変換企画](plans/nimbus-3d-flight-posture-plan-v1.md)。通常の上下維持と拡張技を分け、E3D-01からの再現条件・観測を記載しました。計画であり、上下飛行の実験済みを意味しません。

最新のN02は[走行と全身バランス](experiments/n02-ride-loop-2026-10-25.md)へ進んでいます。首の分散、固定足場、力からの移動と身体応答を一つのループで観測します。旧来の頭保持の成功だけで身体の自然さを判定しません。

仕様化前に乗り方を広げる相談は[乗る姿勢の空想帳](POSE_IDEATION.md)を参照。画像は想像図で、実装済み姿勢や実験順序の変更を意味しません。

2026-10-25：ユーザーがN02筋斗雲サーフ姿勢・U02肩車を選定したため、[ローカル実験](experiments/selected-poses-2026-10-25.md)へ進めました。以下のR01〜R04は初期の実験指針として残します。新しい選定姿勢の確認範囲・未達を読み、実VRM→実XRift→Quest→他者視点を区別して広げます。

## 用意するVRM

最初は標準・今回の小型・別作者の標準の3体。追加でVRM 0.xと1.0、大型、厚い衣服や長い裾のモデルを加えます。同じモデルの拡縮だけでは骨・衣服・エクスポーター差の確認になりません。アバター本体はコミットせず、画面のローカルファイル選択を使います。

## 最初に指定する乗り物と姿勢

複雑な完成モデルは不要です。箱・板の寸法と「どこに何を合わせたいか」があれば比較を始められます。

| ID | 最初の候補 | 身体の狙い | 現在のデモ |
|---|---|---|---|
| R01 | プロペラ／浮遊板 | 直立で頭を保ち、手は自由 | hover / upright |
| R02 | ホバーボード | 足元が板上、膝を少し曲げて上体を傾ける | boardは姿勢だけ。足の接触拘束は未実装 |
| R03 | ハンググライダー | 伏せ姿勢、頭と追跡手を保持 | glider。グリップ／支持面の精密化は次段階 |
| R04 | バイク／狭い操縦席 | 腰を座面、足をステップ、手をグリップ | 未実装。拘束の競合を調べる追加題材 |

1台について指定する項目:

- 前方軸、基準寸法、Seat位置と回転、腰を置く場所。
- 左右のグリップ・足置き・胴の支持面があれば、その位置と許容ずれ。
- 頭・手を追跡のまま自由にするか。PCとVRで同じにする部分／分ける部分。
- 理想の姿勢の側面／正面ラフ、入るとき・乗っている間・降りるときの狙い。

「頭も手も固定し、腰も足も厳密に合わせる」は体格によって同時には成立しません。優先順位は原則、頭・VR追跡手→骨長維持→支持面やグリップへの近さとし、届かない場合を誤差として表示します。用途に応じた別方針は記録して比較します。

## 実験の順序

1. 自作骨格で既存30件を通し、元姿勢→各プリセット→解除を比較。
2. A01 × R01の1組を完成させる。頭・腕・膝・衣服の見え方と解除後の復元を確認。
3. 同じR01へA02とA03を載せる。体格ごとに固定数値を追加する前に、骨の長さ・基準軸・ターゲットのどれが原因か分類。
4. R02／R03へ広げる。移動を加える前に静止状態の支持と姿勢を成立させる。
5. XRift Seatへ接続し、実際の搭乗アニメーションを入力として確認。PC一人称／三人称正面・背面／撮影・ミラー／解除を比較。
6. Questで頭・左右手・指を動かし、遠いグリップへ届かない場合も含める。
7. 最後に別の人の画面、複数人、再搭乗、低FPS、他アイテムとの共存を確認。

## 合格条件と観測

- 単体の頭位置・向きの保持、骨長維持は既存テストの閾値を保つ。実機のトラッキング誤差・フレーム遅延は別に計測。
- 可動範囲内の追跡手は保持。範囲外は骨を伸ばさず誤差を報告。
- 描画終了後と解除後に元の骨の位置・回転・スケールが戻る。入れ子の撮影途中で復元しない。
- 数値に問題がなくても服の折れ・四本脚・視界への頭の入り込みがあれば未合格。正面だけでなく側面から人が見る。
- 非搭乗者の骨やカメラを動かさない。三人称の撮影カメラを操縦基準に戻さない。
