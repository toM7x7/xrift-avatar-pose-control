# 次のスレッドへ

## 採用版からの統合

N02通常飛行1.0.0を採用。[仕様](specs/N02_NORMAL_FLIGHT_V1.md)と[筋斗雲モデルへの引継ぎ](handoff/NIMBUS_MODEL_INTEGRATION.md)を先に読む。基準は `n02-normal-flight-v1.0.0`。JSONを正本として `npm run replay:n02` で固定dtを再現してから、完成モデルとホストへ接続する。以下の実験履歴を、採用仕様の更新や実XRift確認済みと読み替えない。

## 最新：N02の傾斜飛行と頭の上下維持

[傾斜実験記録](experiments/n02-tilted-ride-2026-10-25.md)から再開する。雲pitch/bank→支持面normal/tangent荷重→支持面内IK→世界復帰を実装。頭の入力世界Qを保持し、胸腰を部分補正、左右脚が傾斜を受ける。114テスト・型・build、傾斜14条件、OFFで旧上下14／水平10／姿勢22が成功。手元VRM2体×8状態×3方向×ON/OFF＝96枚を確認済み。

コアsupportFrame省略・dynamics attitudeEnabled既定falseは旧経路。デモは傾斜ONが既定で上限pitch12/bank18度。靴底厚みとCOMheightは支持面normal投影。VRMは元の頭upが約4度ずれるため、flat静止基準とのdelta＋入力Q差で判定する。回転点加速度は未計算とflagを出す。次は乗り味、足首／衣服の余裕、角運動を含む荷重へ。実XRift・Quest・他者・宙返りは未確認。以下は過去時点の履歴。

## 最新：N02の上下運動と胸腰脚

[上下実験記録](experiments/n02-vertical-ride-2026-10-25.md)から再開する。上下推力／抵抗／制動→荷重代理→圧縮応答→胸腰屈伸・脚IKを結合。N02の約9秒コースを可視脚のある手元VRMで観察できる。95テスト・型・build、上下14条件と水平10／旧姿勢22条件、実VRM42枚を確認済み。比較元A03の3枚は自作骨格で無効、最終A03は実VRMと照合済み。

荷重が小さい／負の区間はZMP・足荷重比がnull。利用側は有効性と理由を確認する。足場は水平＋yawのままで、3Dのbank、宙返り、追跡との両立、実XRift／Quest／他者は次段階。まず今回の身体応答の強弱を比べ、その後足場のpitch／bankへ広げる。以下は企画時点と過去実験の履歴。

## 次の企画：N02の3D飛行

[姿勢・変換企画v1](plans/nimbus-3d-flight-posture-plan-v1.md)を先に読む。ユーザー決定は「通常は頭の上下を保ち、宙返り・背面飛行は拡張技」。上下速度と加速度を分け、3D足場・合成荷重・低荷重と魔法の拘束・連続遷移を計画した。企画のみで上下運動や3D支持IKは未実装。次に実験する場合はE3D-01（足場座標と鉛直1軸）から、入力／前後／計測／未達を保存して進める。既存の実装状態は下記。

## 最新：N02の胸腰足・走行ループ

[走行ループ記録](experiments/n02-ride-loop-2026-10-25.md)と[独立観察](experiments/ride-balance-observer-2026-10-25.md)から再開する。首90度集中を腰／背骨／胸／首へ分散し、固定足目標へIKする。力→移動→COM応答／近似ZMP→身体→重心高さ観測のループを実装。78テスト・型・build、走行10条件、旧頭優先22条件、A01/A03の30枚を確認。

制動の空気椅子状の沈み込みは腰高さ平均・膝表現上限・高さfeedbackで改善。原VRMや私有画像は非公開のまま。これは全身剛体接触の完成ではなく、通常入力での近似バランス＋IKの実験。次は乗り味・動的な肩腕・体格／衣服差の見た目を確認し、実XRift／Quest／他者へ広げるときは別に境界を検証する。

## 最新：持込VRM3体・腕の調整後

[実VRM記録](experiments/real-vrm-2026-10-25.md)と[腕の調整記録](experiments/n02-arm-refinement-2026-10-25.md)を先に読む。3体ともVRM0で、向き・模擬入力・靴底候補を補正。N02は盆を持つような腕を、掌下・肘から手先へ下降・前低後高の構えへ変更した。最終56テスト・型・ビルドと、自作22条件、実VRM27条件＋腕12方向を確認。腕の最終的な格好よさはユーザーの判断を受ける。

A02は脚骨があっても可視脚がないため足裏合格の対象から外す。A03の肩車は衣服・股・頭周辺の干渉調整が残る。私有モデルと画像はlocal-assets/とvrm/に保持し、公開物へ含めない。

## 最新の継続対象：N02筋斗雲・U02肩車

ユーザーが空想帳のN02とU02を選び、サブエージェントで実装・観察を並列に進めることを希望。ローカルデモへ追加し、48テスト・型・ビルド、ブラウザ22条件、初版〜v3の画像27枚を確認しました。小型の乗る側×大型の運ぶ側の肩車は脚と胴の干渉が残り未合格です。次は[実験記録](experiments/selected-poses-2026-10-25.md)と[観察記録](experiments/observer-2026-10-25.md)を読み、手元の実VRMでN02の足裏・衣服、U02の頭・腿・肩支持を比較してください。XRift／Quest／他者同期はまだ未確認です。

支持優先での描画頭移動をVR追跡と両立したと扱わないこと。頭保持優先の支持ずれ、届かない手、深いしゃがみの未達も観測対象です。初版画像を残して修正版と比較し、元アイテムへの反映は別依頼として扱います。
