ユーザー決定：**通常飛行は頭の上下を保つ。宙返り・背面飛行は拡張技に含める。** N02のサーフ姿勢を基本にし、胸・腰・脚の踏ん張りと腕の構えで操縦を見せる。

## 1. 目指す体験

「斜め上へ一気に飛び出す → 上空でふっと荷重が抜ける → 身体を小さくして降下 → 脚でぐっと受けて引き起こす → らせん状に上昇 → 空中でぴたりと止まる」を、同じ身体の連続した動きとして成立させる。

筋斗雲には、空中で前後・左右・上下へ動ける自由と、乗り手が足で受けている実感の両方を持たせる。真上へ進む時も、足場は乗り手が立てる傾きに保てる。雲の進行方向、足場の傾き、身体、視線にそれぞれ役割を持たせる。

通常の操縦は次の形を第一候補とする。

- 前後左右の推進と、上昇・下降を独立入力。横移動や後退もできる。
- 操縦の基準方向を明示して保持する。観察カメラを回しても進行方向は変わらない。
- 通常は入力を離すと減速してホバー。惰性を楽しむモードは別設定で比較する。
- 視線は自由。見上げ続けなくても上昇でき、見下ろすだけで急降下しない。
- 視線で操縦する方式は選択肢として残し、垂直付近では直前の水平方位を引き継ぐ。
- 急加速・急旋回は、通常操縦の上に重ねるブーストとして調整する。

PCの具体キーとVRのボタン割当は利用側の入力契約を確認して決める。姿勢コアには正規化した操縦意図だけを渡す。

## 2. 動きの絵コンテ

以下は独立した固定ポーズ集ではなく、連続した制御を観察するための代表場面。

| 場面 | 飛行・足場 | 腰・胸・脚 | 腕・頭と戻り方 |
|---|---|---|---|
| 待機・ホバー | 高度と方位を保持 | 現在のN02を少し余裕のある膝へ。荷重は落ち着く | 肩を上げず、掌は低く。周期的な揺れを自動追加しない |
| 斜め上へ発進 | 前進と上向き加速を合成。雲の前端は軽く上がる | 短い慣性遅れを脚・腰で受け、腰を加速方向へ。上向き加速分を膝で圧縮 | 胸は行き先へ、腕は前低・後やや高の構え。巡航へ入ると圧縮を戻す |
| 真上へ上昇・その場降下 | 水平方位は維持。足場はほぼ水平でもよい | 発進・制動時だけ荷重が変化。等速区間は通常の踏ん張りへ | 頭を雲の進路へ90度折らない。本人の見上げ・見下げは維持 |
| 上昇を止めて浮く | 上向き速度に対する下向き制動で軽くなる | 膝の圧縮がほどけ、腰が少し高くなる。脚は伸び切らせない | 肘・指の緊張を緩め、再ホバーで構えが静かに戻る |
| 急降下へ入る | 下向き加速。足場のpitchは通常範囲に保つ | 荷重が抜ける。胸と腰を寄せて小さく構える動作は、能動的な技として加える | 腕を身体の近くへ。速度による風の演出と荷重の反応を分ける |
| 急降下から引き起こす | 上向きの加速度で下降を止め、水平へ | 脚でぐっと受け、左右・前後の膝に差をつける。過大な沈み込みは制限 | 胸は次の進行へ向き、肩・肘が釣り合いを補助。荷重が戻るにつれて解放 |
| 上昇しながら旋回 | 上下と旋回の加速度を合成。雲は内側へbank | 合成した荷重方向へ腰・胸・脚を配分。上昇用・旋回用のしゃがみを二重加算しない | 胸は旋回先へ、頭は本人の視線。左右非対称の腕で釣り合いを見せる |
| 横へかわす・後退 | 身体の正面と移動方向を別々に保てる | かわす瞬間と止める瞬間で荷重移動を反転。後退だけで全身を180度反転させない | 低い腕の構えを軸に、肘の開きと手先の位置を調整 |
| 空中急停止 | 速度と逆向きの制動を全軸に適用 | 実際の減速度を脚で受ける。停止後は残留する身体の動きを減衰 | 胸・肩が遅れて落ち着く。次の入力で待機姿勢を経由せず連続的に切り返す |

頂点の高度や、上下速度が0になった事実だけでは無重力にしない。降下中でも、下向き速度を止める時は重くなる。

### 最初に見たい一連のコース

約25秒の固定入力を第一候補にする。区間長は再現用で、カット時刻に合わせたポーズ再生にはしない。

| 時間案 | 入力の意図 | 見たい変化 |
|---|---|---|
| 0–3秒 | ホバー → 斜め上発進 | 押される → 脚で支える |
| 3–6秒 | 上昇巡航 → 上昇制動 | 圧縮が戻る → 荷重が抜ける |
| 6–9秒 | 横へかわしながら下降開始 | 軽い構えと横への釣り合い |
| 9–13秒 | 急降下 → 引き起こし | 小さく構える → 脚で受け止める |
| 13–19秒 | 左らせん上昇 → 右へ切り返し | 合成荷重と胸・腰・腕の向きの連続性 |
| 19–25秒 | 斜め制動 → 空中停止 | 圧縮 → 減衰 → ホバー復帰 |

## 3. 移動と姿勢をつなぐ原理

### 加速度から荷重を求める

世界座標の重力を `gWorld = (0, -g, 0)`、足場の加速度を `aSupport` とする。最初の近似は次の通り。

```text
見かけの重力方向 = gWorld - aSupport
支持に必要な加速度の代理 = aSupport - gWorld
法線荷重の倍率の代理 n = dot(aSupport - gWorld, supportNormal) / g
```

水平で回転しない足場なら `n = 1 + aY/g`。これは足場と一緒に移動する点質量の近似であり、実際の足圧や筋力の計算ではない。

| 鉛直方向の状態 | 加速度 | 荷重の方向性 | 姿勢の主な反応 |
|---|---|---|---|
| 上昇加速／下降制動 | 上向き | 増える | 脚で受け、圧縮を増やす |
| 上下とも等速 | 0 | 通常へ | 無用なしゃがみを戻す |
| 上昇制動／下降加速 | 下向き | 減る | 圧縮がほどけ、軽い構えへ |
| 自由落下に近い加速 | 重力に近い | ほぼ0 | 通常の足荷重表示を停止し、低荷重状態へ |
| 足場へ引き付ける力が必要 | 法線方向で負 | 押す接触だけでは維持できない | 魔法の拘束として扱う |

例として `aY = +3 / 0 / -3 m/s²` を与えると、水平足場の代理荷重は約 `1.31 / 1.00 / 0.69` 倍。同じ速度で比較しても姿勢が区別できることを最初に確認する。

ニュートンの運動則と自由落下の関係は[NASAの解説](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/free-fall-without-air-resistance/)を参照。上式はそこからの導出で、雲の推進・吸着はこの企画の設計判断。

### 動く足場を共通座標にする

足場は位置とquaternionで表す。前・右・上はそこから導出し、相互に矛盾する入力を増やさない。足首目標、足裏、COM、腰高さ、支持多角形を同じ足場座標に変換する。現在の世界Y固定・XZ投影・yawだけの回転を、3D足場へ広げる。

真上・真下・速度0では速度ベクトルから前方を作り直さず、操縦基準と直前の方位を継続する。姿勢の補間には最短回転を使い、角速度の連続性も見る。コアの前方を+Zと定義する案とし、ホストの軸・単位は境界で検証して一度だけ変換する。

旋回中は接地点や乗り手の高さに応じた加速度も生じる。第1段階は並進加速度だけ、第2段階で足場の角速度・角加速度と乗り手までの距離を含める。世界座標で求めた点の加速度へ回転項が含まれている場合、同じ項を再加算しない。実現したCOMの相対運動も観測し、足場原点の代理との違いを記録する。

bankは旋回加速度に応じて目標を作るが、筋斗雲は全方向推力を持つ設定。傾きだけで移動を決める航空機モデルには固定しない。bankと向心加速度の関係の参考は[NASAの旋回解説](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/aircraft-motion-turns/)。

### 通常支持・低荷重・魔法の拘束を分ける

| 支持状態 | 足と雲の関係 | 計測と変換 |
|---|---|---|
| 通常支持 | 足場が身体を押し支える | COM、支持域、ZMP・荷重比の代理を表示。正の法線荷重と摩擦の条件を見る |
| 低荷重 | 足を押し付ける力が小さい | ZMP／前後荷重比は無効値と理由を返す。脚の圧縮を緩める |
| 魔法の拘束 | 雲が足を引き留め、接線方向も支える | 足の接続と必要な拘束の代理を表示。圧縮荷重と区別する |
| 足の離着・踏み替え | 接触する足を明示して切り替える | 非支持側だけ目標を動かす。低荷重なら吸着を使うか、身体の浮遊を別計算する |

低荷重から通常支持への復帰には別の閾値と短い保持時間を設け、境界で毎フレーム切り替わるのを防ぐ。最初の数値案は `n < 0.15` で低荷重、`n > 0.25` で復帰。数値安定と表現のための仮値で、人体の基準ではない。負の荷重は閾値待ちで通常接触として扱わない。

全方向へ自由に操縦できる通常モードでは、足の接続を補助する魔法を利用可能にする案。必要な場面だけ有効にし、実験表示に状態を出す。魔法なしの比較モードでは、接触条件を満たすよう加速度・bankを制限する。摩擦だけで横滑りを防げない条件も同様に扱う。

## 4. 姿勢の作り方と変換

### 四つの役割

1. **飛行軌道**：全軸の推進・重力を支えるホバー力・抵抗・制動から運動を計算する。
2. **足場の姿勢**：進路や加速度から緩いpitch／bankを作る。急な角速度も制限する。
3. **乗り手の身体**：荷重方向と支持状態から、腰の移動、胸の向き、膝の圧縮、腕を解く。
4. **視線・追跡**：本人の頭とVR追跡手を入力として扱う。通常飛行の足場bankでカメラを回さない。

雲が上昇する角度、足場のpitch、胸の前傾、頭のlookは別の量として扱う。真上へ飛んでも、乗り手が直立に近いまま足で受ける構成を選べる。

### 連続量と状態を併用する

連続量は「法線荷重・接線荷重・COM偏位・速度／風・旋回率・加速度の変化」。状態は「通常支持・低荷重・吸着・踏み替え・技」。これらから毎フレーム姿勢を求める。上昇と旋回などを同時に入力した場合も、一つの合成された釣り合いとして解く。

入力に対する短い予備動作は、能動的な構えの層として加える。荷重の計算を先に捏造せず、予備動作と実際の慣性応答を別に記録する。入力を急反転してもポーズをリセットせず、現在の腰・胸・膝・応答速度から次へつなぐ。

制御の順序案：

```text
操縦意図 → 推力・制動と加速度の変化の制限 → 3Dの運動
        → 足場の姿勢・接地点の運動
        → 見かけの荷重・支持状態
        → COM／胸／腰／膝／腕の目標 → 足と骨長を保つIK
        → 実現したCOM・到達誤差・限界を観測 → 次フレームへ
```

膝の圧縮と腰の前後左右移動は個別に調整する。荷重の増加をすべて腰下げへ変換しない。膝が既存の表現上限に近づいたら、姿勢側は未達を返し、操縦側で加速度・引き起こしの鋭さを緩める選択をする。姿勢コアが直接Vehicleを動かす構成にはしない。

### 身体各部の方針

- **足**：接地中の目標を足場ローカルに保持。足裏の位置と向き、足首の可動余裕を確認する。支持中に足幅を滑らせない。
- **脚・腰**：骨長を維持し、荷重とCOM目標へ合わせる。踏み替えは左右の支持を計画した追加段階とする。
- **胸・首**：今の斜め構えを基準に、胸・背骨・腰へ向きの差を分配。強い見回しでは胸も追従し、首だけへ集中させない。
- **腕**：肩・肘・手先の順に外下へ流す基本を維持。旋回・制動では左右差を変え、低荷重では緊張を緩める。VRで追跡している手は本人の動作を優先する。
- **頭**：通常飛行では強制反転しない。本人のlook入力を保つ。頭の世界位置と足支持が競合する場合は、選んだ優先方針と残差を明示する。

PC三人称の支持優先と、VR追跡優先は別に受け入れる。VRの頭を足場へ合わせるために描画カメラを動かして成立扱いにしない。両立しない時はbankを弱める、姿勢を浅くする、到達誤差を出す、の順で比較する。

### 最初の調整つまみ案

| つまみ | 第一候補・比較対象 |
|---|---|
| 操縦 | 全方向推進、独立した上下、減速ホバー。視線操縦は選択制 |
| 通常の雲の傾斜 | pitch ±20度／bank ±25度を比較開始の仮値とする。軌道の上昇・降下角は別 |
| 機動 | 通常／ブースト。速度・加速度・加速度の変化を別に調整 |
| 身体 | 荷重圧縮、COM移動、胸の先行、腕の反応、減衰 |
| 支持 | 魔法の補助あり／接触条件で機動を制限する比較 |
| 観察 | 入力再生、一時停止、正面・側面・斜め、速度と加速度の矢印 |

この数値とつまみは企画案。全アバター共通の確定規格にはしない。

## 5. 宙返り・背面飛行の拡張

通常飛行の受入後に追加する。

| 技 | 身体・足場 | 視線と成立条件 |
|---|---|---|
| ループ飛行 | 軌道だけが縦の輪を描く。足場と乗り手は上下を保つ方式から開始 | 通常飛行の延長。上部の低荷重・下部の強い荷重を確認 |
| 身体も回る宙返り | 足を魔法で保持し、雲と身体が一緒に360度回る | 通常の上下維持を技の間だけ解除。PC演出用から検証 |
| 背面飛行 | 雲と身体が反転したまま移動 | 吸着が必須。通常の足圧・ZMPとは別の拘束を表示 |
| 雲だけ一回転 | 乗り手は一時的に足を離し、雲が回って戻る | 離着と再接続が必要。固定した両足のまま全回転させない |

VRはHMDを直接回転させる方式を通常設定へ入れない。拡張技の一人称で何を見せるかは別の受入項目にし、まず他者視点・PC三人称で成立を確かめる。技の開始・取消・終了から通常N02へ戻る経路も用意する。

| 運動 | 速度・加速度・角速度・角加速度、単位と座標系、観測／予測の区別 |
| 操縦意図 | 3軸推進・旋回・制動・ブースト・技。入力を扱う所有者 |

共通規格には「3Dの足場・運動・支持の種類」を持たせ、筋斗雲の浮力や魔法、腕の表現はN02側の方針とする。将来の動物・幻獣・U02へ渡す時も、揺れる背中や肩を動く支持点として表現できる余地を残す。今回はU02の姿勢変更・動力学は追加しない。

利用側が移動と同期の権限を持ち、姿勢側は観測と要求を返す。XRiftへの接続時は、現在のホスト契約を確認してから、同期済みの運動を使って姿勢を再構成する。骨の姿勢が他者へ自動同期すると仮定しない。

| E3D-03 | 低荷重・魔法の拘束、引き起こし、連続した身体応答 | ZMP無効化、状態往復の抑制、再支持、過大なしゃがみの回避 |
| E3D-04 | 絵コンテの固定入力・手動操縦・体格比較 | 加速から復帰までの見た目、腕の自然さ、服・髪、操作の気持ちよさ |
| E3D-05 | 軌道ループ → 身体の宙返り・背面・雲だけ回転 | 明示した技と拘束、取消・復帰、通常モードへの漏れなし |
| 接続段階 | 実XRiftで搭乗 → N02 → 3D飛行 → 降車 | 本人／他者、PC／Quest、追跡、同期、衝突を個別に確認 |

最初の変更候補は `src/ride-dynamics.*` の3軸力学、`src/nimbus-pose.*` の支持面・荷重・IK、`demo/main.mjs` の上下入力と再生観測。現在のexportを使う側を壊さない入口を検討し、平面版を回帰比較に残す。

### 最初の数値実験

1. 水平ホバーと、等速上昇／下降。速度は±2m/s、加速度は0として荷重代理が同じになること。
2. 上下速度±2m/sの各状態で、加速度±3m/s²を短区間与える4組。重い／軽いの分類を逆にしない。
3. 加速度を重力に近づける低荷重テスト。無効なZMPを0やNaNで合格扱いしない。
4. 低荷重→引き起こし→通常支持。状態の切替、足目標の跳躍、膝の過圧縮を確認。
5. 左右の同じ旋回、らせん上昇、斜め停止、速度0からの垂直移動。対称性と方位連続性を見る。
6. 同じ時系列を30／60／120fps、短いフレーム停止、pause／再開、降車で比較。

加速度を直接渡す数値試験と、操縦入力から実加速度を測る統合試験を区別する。自作骨格→A01/A03の実VRM→実XRift→Quest→他者の順に進める。可視脚がないA02は、足裏の目視受入対象から引き続き外す。

### 保存する観測

- 入力時系列、seed、dt、初期状態、設定、モデル識別子、変更前後の同一条件。
- 位置・速度・実加速度・足場回転、法線／接線荷重の代理、支持状態と切替理由。
- 足場内の足滑り、足裏のgap・向き、骨長、首／胸／腰／膝／足首、COM残差と支持域。
- ZMPや荷重比を計算しない区間の理由、吸着が必要になった区間、制限された操縦量。
- 頭と追跡手の目標差、カメラの所有権、非搭乗者不変、描画後・降車後の復元。
- 正面・側面・斜めの同時刻画像と連続動画。数値が合っても身体・服が崩れれば未合格。

各段階で実行前に数値許容差と観察判定を固定し、結果を見てから合格線を動かさない。今回の企画作成では上のE3D実験は実行していない。

## 8. 今回の判断と残る確認

確定した方向：N02を基準とする全方向飛行、通常の上下維持、宙返り・背面は拡張技。上下加速度と合成荷重を姿勢へ渡し、低荷重と魔法の拘束を区別する。

比較して選ぶこと：減速ホバーの強さ、ブーストの鋭さ、雲の傾斜、予備動作の量、吸着の見せ方、追跡と支持の競合時の乗り味。

未確認：3D支持IKの実VRMでの自然さ、足首と服の限界、実際の接触力・摩擦・全身剛体、地形や障害物との衝突、XRiftの姿勢接続、Quest一人称、他者同期。全身剛体や筋肉のシミュレーションの完成を、この企画の前提にしない。

サブエージェント2担当が読み取りレビューを実施。姿勢側からは「飛行軌道と足場の傾きを分ける」「引き起こしで膝を潰さない」、観測側からは「3D足場を先行」「低荷重のZMP無効化」「垂直時の方位継続」を受け、本案へ反映した。

今回の成果物はこの企画と参照リンク。実装・ブラウザの見た目・既存アイテム・公開状態の変更はない。
