# 多姿勢・持込VRMのパターン探索 v1

2026-10-25。筋斗雲以外へ広げるユーザー依頼を受けた実験計画。乗り物モデルの制作は含めない。既存N02採用profileを保持し、新しい候補は未採用として比較する。

## 比較するもの

立つ、踏ん張る、胸を預ける、椅子座り、またがり、横座り、肩車の7系統・18候補。候補の意味・設定は`src/pose-patterns.mjs`、適用は`demo/pattern-engine.mjs`に分ける。

各候補に基本・強弱・支持pitch/roll・見回し・模擬追跡手・family専用の幅や支持高など18の通常条件を作る。境界条件を含む30条件へ拡張する。全軸の総当たりではなく、意味のある選定条件である。実VRMを拡縮して別モデルとして数えない。

## 二段階の実VRM探索

1. stressの540条件を3体それぞれ一度ずつ、同じ最終支持状態で解く。standard324はstressへ含まれる。
2. モデルごとに各候補の基本形と厳しい条件を最大1つ選び、最大36条件を固定dt1/60・24フレームで確認する。
3. 基本形を正面・側面、境界の代表を複数方向で撮影する。全条件の数値検査と、選んだ画像の目視を別々に数える。

これは支持姿勢とIKのkinematic sweepである。力の積分・全身剛体接触・自己衝突・摩擦・布・転倒の物理計算ではない。N02の採用済みforce-driven飛行の再現は引き続き`npm run replay:n02`で行う。

自作骨格は別に3体格×324条件×24フレームをCPUで確認する。実VRM試験の代用とはせず、私有素材なしの再現経路として残す。

## 判定を分ける

- 数値破綻：非有限の骨・計測、骨長の変化、頭の入力Qの変化、適用／復元失敗。
- 到達の限界：腰・足・手・運ぶ側の手の未達、膝と頭首角の実験閾値超過。
- 支持の未確認：足の可視形状なし、座面／服の接触未測定、支持面から外れる条件。
- 見た目：腕の役割、肘と手首、首へ集中しない姿勢、衣服、足の浮き、身体同士の重なり。

`pass`は数値screenの成立だけを意味する。画像の採用判定、実XRift・Quest・追跡入力・他者同期の確認とは別。

## 保存

私有VRM・個別画像・全数の詳細JSONはignoredの`vrm/`・`local-assets/`・`artifacts/`に置く。公開可能な資料は匿名の集計・設定・再現手順だけにする。入力モデルは選択順の匿名IDと頂点／可視foot診断で照合し、以前の匿名IDとの一致を名前から推定しない。
