# N02：上下移動と胸・腰・脚の連動

2026-10-25。[3D飛行企画v1](../plans/nimbus-3d-flight-posture-plan-v1.md)から、上下の推進・制動と身体応答を実装した。ユーザーの依頼範囲は、まず手元のVRMで確認できるところまで。

## 今回できること

- 上昇・下降・全方向の制動。前進や左右旋回との同時入力。
- 上昇加速／下降制動で荷重が増え、上昇制動／下降加速で荷重が減る。
- 荷重の変化に胸・腰の屈伸、両膝、腰の高さが連動し、停止すると基準のN02へ戻る。
- 雲に保存した足首目標を高度に合わせて運ぶ。足場の姿勢は水平＋yawのまま。
- 上昇→制動→下降→制動の約9秒コース、一時停止、複数視点、開始位置からの高度差表示。

企画のE3D-01の鉛直運動と支持点の3軸平行移動に着手した段階。任意quaternionの支持面、bank、宙返り、背面飛行は今回の実装に含めていない。

## 触り方

1. `npm run dev` → http://127.0.0.1:5228/ 。N02・「足場へ踏ん張る」を選ぶ。
2. 「手元のVRMを読み込む」で可視の脚・足があるVRMを選択する。複数選択後は一覧で切替可能。
3. 「上昇→制動→下降→制動を試す」を押す。膝だけでなく、腰の高さと胸の屈伸を見る。
4. 「動きを一時停止して観察」と正面／横／斜めで確認する。手動なら「上昇」「下降」「全方向を制動」。
5. 「停止・戻す」は開始位置へ戻す。「全方向を制動」はその場で減速して停止する。

ボタンは継続する推力の切替。入力を離す操作に当たる「惰性」は推力0と抵抗のみで、自動の高度保持controllerとは別。ホバーを支える基礎浮力は常時あり、停止後は高度が維持される。上向きから下向きへ切り替えても速度は即反転しない。

## 入力・計算・身体への伝達

デモの設定は質量70kg、上下推力各210N、鉛直制動210N、鉛直の線形抵抗20・二次抵抗1。抵抗0なら上下加速度は±3m/s²。実際の加速度には抵抗・制動・停止時の速度制限が入るため、画面では実測した値を表示する。

運動側は重力と基礎浮力を相殺し、追加の上下推力と抵抗を積分する。`normalLoadRatio = (gravity + verticalAcceleration) / gravity` を、水平足場の荷重倍率の代理として出力する。重心・ZMPの分母も有効法線加速度へ拡張した。

荷重差を時定数0.18秒で圧縮量へ変換する。従来の水平crouchと別に出し、姿勢側で一度だけ合成。胸・腰へ小さな相対屈伸を配分し、足固定と骨長を保って脚IKを解く。首の世界向き、胸腰へのyaw配分、既存の膝表現上限100度を維持する。これは縮約した能動バランスと姿勢制御で、全身の質量・関節トルクを解いたものではない。

足目標は毎フレームの姿勢結果から再配置しない。初回に校正した雲ローカル座標を、雲の位置・yawで世界座標へ運ぶ。COM高は `COM.y - contactPlaneY` として測り、絶対高度を高さfeedbackへ混ぜない。

低荷重ではZMP／足荷重比／支持余裕を`null`にし、理由を返す。負荷重は即`adhesion`、低荷重からの復帰は閾値と保持時間を使う。足を接続したままにする状態は魔法の拘束として区別する。通常UIの±3m/s²付近ではこの境界へ入らず、数値実験で検証した。

## 実VRMの結果

可視の脚があるA01/A03で、静止・上昇加速・上昇制動・上空停止・下降加速・下降制動・停止復帰の7状態×3方向＝42枚を保存。モデルのprofile・skin数・頂点数も照合した。A02は可視脚がなく、足裏の受入対象にはしていない。

| 状態 | A01 平均膝角 | A03 平均膝角 | 荷重倍率の実測目安 | 胸と腰のpitch差の目安 |
|---|---:|---:|---:|---:|
| 静止 | 67.0度 | 67.0度 | 1.00 | 0度 |
| 上昇加速 | 70.9度 | 70.9度 | 1.22 | +2.6度 |
| 上昇制動 | 62.6度 | 62.6度 | 0.65 | -2.9度 |
| 下降加速 | 63.1度 | 63.1度 | 0.78 | -2.6度 |
| 下降制動 | 71.4度 | 71.4度 | 1.35 | +2.9度 |
| 停止復帰 | 約67.0度 | 約67.0度 | 1.00 | 約0度 |

上昇中も制動すると軽くなり、下降中も制動すると重くなることを内部比較で確認。荷重だけで姿勢を即切替せず、圧縮量が連続して変化する。腰の支持面からの高さは、軽い時と重い時でA01約4cm、A03約5cmの差が出た。停止後は基準へ戻り、首yawは両モデル約8度を維持。

全42条件で足首目標差は1mm未満、骨長差は数値上ほぼ0。描画頂点から測った靴底候補と足場の高さの差は最大A01約0.011mm、A03約0.0011mm。骨点・頂点の代理計測であり、実足圧や接触力の精度を保証する数値ではない。

独立担当が42条件を集計し、8枚を目視。重い時の小さな沈み込みと胸の屈曲、軽い時の伸び、足と首の安定を確認。前回の空気椅子状の過沈下は再発していない。変化量は控えめで、乗り味や格好よさの最終判断は継続する。

### 比較元の扱い

統合前に6枚を撮影したが、並列実装中にdynamicsが既に更新されていたため、旧版の上下力学のbeforeとしては扱わない。A01の3枚は実VRMの静止姿勢として有効で、最終静止時の膝・頭・足は同じ数値だった。

A03とラベルした比較元3枚は読込が成立せず、自作骨格だったことを独立観察で検出。採否・前後比較から除外し、元の記録は残した。最終A03の21枚は実VRMであることを診断値から確認している。

## 制限と次の実験

足場は水平＋yawであり、bankや傾斜面への足裏IKは未実装。通常UIの上下入力は段階的な力で、推力のjerk制限や踏み替え、動的な腕の演技は次の調整。身体の上下応答の連続性を、全身の物理接触・摩擦・転倒の完成とは扱わない。低荷重の魔法拘束も仮の足接続で、拘束力を同時に解くsolverではない。

カメラの追従はこのデモだけの明示設定。追従オフ時に姿勢・上下移動からカメラを動かさないことを確認した。支持優先で頭が動く今回の観察を、VRの頭・手追跡との両立と扱わない。実XRiftへの接続、Quest、他者同期、障害物・地面の衝突、宙返り・背面飛行は未確認／未実装。

次はこの連続コースで身体応答の強弱を選び、水平加速と上下の合成を見ながら、足場のpitch／bankと足裏姿勢へ進める。今回、既存アイテムへの反映・アップロード・公開は行っていない。
