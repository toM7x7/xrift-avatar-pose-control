# 両手で持つポンプ式の玩具（持ち物を持つ動作）の実験（2026-11-10）

ユーザー依頼「カメラモードにするとアイテム（塩を撃つポンプ式の玩具、items/shio-machinegun）がカメラに付いてアバターから離れる。うまく手元に置いてほしい。ついでにこのリポジトリを参考に、いろんなアバターでリロード・ポンプアクション風に動くようにしてほしい。試行錯誤もポーズ調整として載せる。ボーンの対応も忘れずに」。

これまでの動作（charge-wave）は「立ち止まって構える→溜める→放つ」で、全身を上書きしていた。今回は **歩きながらずっと持っている物** なので、前提が2つ違う。

1. 下半身はホストの歩行・走り・ジャンプのまま。上書きしてよいのは背骨・鎖骨・腕・指だけ。
2. 手の行き先は体の前の決まった点ではなく **持ち物の上の決まった場所**（握り・ポンプ・フタ）。ポンプが動けば手も動く。

## 足した仕組み

- `applyAuthoredPose(..., {lowerBody:'host'})`：骨盤と脚に触らない。背骨はホストの骨盤の向きから作者の胸の向きへ配分する。足はホストの位置を測るだけ（重心・足の滑りの検査用）。
- `src/authoring/prop.mjs`（持ち物）：
  - 持ち物を体の座標（肩からのずれ・向き）に置き、持ち物の **ソケット**（位置・指の向き・手のひらの向き・動く向き）から手の目標を作る（`placeProp`・`socketTarget`・`sampleHeld`）。
  - 相ごとの振り付けはクリップの曲線（`phases`：ポンプの移動量・フタへ手を伸ばす量・フタの持ち上げ・構えの切り替え・引き金の指）。アイテムは自分の機構の「相と進み具合」を渡すだけ（`heldParams`）。検査は同じ曲線を `timeline` で通す（`timelineParams`）。
  - `holdFit`：持ち物は実寸なので、体が小さいと支える手が届かない。体ごとに一度だけ、①持ち物を体格に合わせて縮める（`prop.fit.scaleBelow`、任意）②胸をさらに回して支える側の肩を前へ（6°刻み・18°まで）③持つ位置を胸へ寄せる（1.5cm刻み・18cmまで）の順で、全部の確認姿勢で両腕が届き肘が伸び切らない最小の調整を探す。
  - `applyHeld`：1フレーム解いて、持ち物のワールド姿勢を返す。握る手が届かなかったら持ち物の方を手へ寄せる（`shortfallMm`）。
- 検査：`evaluateHeld`（`evaluateAction` と同じループを共有）、`npm run review:pump-gun`（3体格＋静止姿勢の腕の数値）、`npm run fit:pump-gun`（持つ位置の探索）、`npm run review:compat:pump-gun`（骨格21変種）。
- 題材：[specs/pump-gun.v1.json](../../specs/pump-gun.v1.json)。参考画は items/shio-machinegun の `concepts/`（Codex の画像生成、完成予想・分解図・動作図）。

## 実VRM（items/shio-machinegun の検証ページ、XRiftと同じ読み方）

撮影は items 側の `output/pose/`（非公開）。10相（構える途中・ポンプ引き・待機・連射・撃ち切り・フタ回し・フタ持ち上げ・握り直し・見上げ・見下ろし）の静止。

| 体 | 読み方 | 調整 | 手の未達（左右・全相の最大） |
|---|---|---|---|
| 木製デッサン人形（items の dev-assets、配布しない） | 名前 | 胸+18° | 0.00 / 0.00 mm |
| A01 標準・小柄寄り | 名前 | 胸+18°・寄せ4.5cm | 0.00 / 0.00 mm |
| A02 手足の重みが無いモデル（頭が大きく体がとても小さい、Blender式の名前） | 名前＋形 | 持ち物0.60倍・胸+18°・寄せ1.5cm | 0.00 / 0.00 mm |
| A03 別作者・太いズボン | 名前 | 胸+18°・寄せ1.5cm | 0.00 / 0.00 mm |

A02 は縮める前、寄せを上限の18cmまで使っても条件（肘14°以上）を満たせなかった（`reached:false`）。持ち物が体と同じ長さで、見た目も「銃を抱えた頭」になっていた。体の単位が0.85を下回る体では持ち物を体格の比で縮める（下限0.5）ことにして、両手で構えた姿になった。

見た目の判断（数値とは別）：

- 外から：待機・ポンプ引き・見上げ・見下ろし・連射は両手で持った姿として自然。フタは左横からつかんで見える（最初は開いた手が上を向いて「手を振っている」ように見えた→指を82°曲げる）。
- 自分の目（一人称）：腰だめの構えだと銃は画面の下端に筒先が見えるだけだった。自分の目で見ているときだけ高い構え（握りを肩から下15cm・前31cm）にすると、フタ・筒先・左手が画面下に入る。他人の画面とカメラモードでは腰だめのまま。

## 判断

- 持つ位置は見た目の好みより先に関節の余裕で決めた（`fit-hold` の格子探索）。胸の高さで握ると、肘をどちらへ出しても手首が伸展か尺屈のどちらかで大きく折れる。腹〜腰の高さで前腕がほぼ前を向く持ち方が楽。
- 連射中（毎秒13回、ポンプは8.5cm往復）は手をポンプに全部ついて行かせない（`follow` 0.22、約2cmの震え）。全部ついて行かせると腕が毎秒13回、0.7m/s を超えて往復する。
- 手動のポンプ（持った直後と装填のあと）は全部ついて行く。機構の側に「構える0.3秒」と「握り直す0.26秒」の相を足した（手がポンプに着く前にポンプが動かないように）。
- VR の人には当てない（手は追跡されている）。骨が読めない体にも当てない（アイテムは体の脇に銃を描く）。

## 未確認

- 実XRift（PC・スマホ・Quest）、他者視点、カメラモードの実機。ホストが一人称で自分の体（頭なしの写し）を描くかどうかで、自分の腕の見え方が変わる。
- 歩行・走行中のホストの姿勢の上での見え方（検査は待機姿勢だけ）。骨盤が揺れるぶん、胸の向きは少し揺れるはず。
- 下を35°見たとき、大きい体の高い構えで右手首の尺屈31.6°（閾値30、警告）。
- 実VRMは静止10相の未達だけを数値で見た。全タイムラインの数値検査（関節の速さ・跳び）は自作骨格だけ。
- Pose Studio は持ち物のクリップを表示できない（今回は items 側の検証ページで見た）。
