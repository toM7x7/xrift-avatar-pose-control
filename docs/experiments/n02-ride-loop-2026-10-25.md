# N02：胸・腰・足と走行力の連動実験

2026-10-25。ユーザーの「身体が横向きで首だけ90度は人間らしくない」「胸・腰・足の踏ん張りと前進へ物理演算が必要」という指摘から改訂した。N02の局所ポーズ調整を、雲の運動・支持・全身の釣り合いがつながるローカル実験へ進めた。

## 触り方

npm run dev → http://127.0.0.1:5228/

1. N02を選び、姿勢の基準は「足場へ踏ん張る（観察用）」。
2. 「前進」「左へ」「右へ」「惰性」「制動」で力の入力を変える。
3. 「発進→旋回→制動を試す」は入力区間を順番に再生する。移動状態は毎フレーム力から計算する。
4. 「動きを一時停止して観察」でその状態を止め、正面・横・斜めを比較する。
5. 「重心・荷重の目安を表示」で足荷重とZMPの近似位置を見る。「停止・戻す」で初期化。
6. 手元のVRMを複数選ぶと一覧で切り替えられる。今回の足支持の目視対象は可視脚のあるA01/A03。A02は脚形状がなく対象外。

観察視点の移動追従はデモのOrbitControlsに対する任意設定。姿勢コアからカメラ・実VR入力は変更しない。頭位置を保持する比較モードも残すが、支持優先との同時成立を意味しない。足幅を変更すると停止・初期化する。

## 旧版の根因と変更

旧版は腰・背骨・胸・首を同じ90度へ向け、頭だけ元の世界回転へ戻していた。頭位置の誤差0mmでも、ねじれが首へ集中した。

初期姿勢は足62度・腰50度・背骨約33.5度・胸20度・首8度・頭0度へ段階的に配分する。大きな見回しでは胸も適応し、首側へ残りすぎる条件は未達として出す。これはN02の見た目方針であり、医学的な可動域の規格ではない。腕は胸の向きへ追従する。

旧版では雲がその場の足の結果へ移動していた。新版は初回に両足首の雲ローカル座標を保存し、走行中は雲の位置・向きで運ぶだけにした。腰・胸・膝を解いて足をこの固定目標へ合わせる。靴底候補の測定オフセットで接触面を区別し、足と骨長を優先する。

## 力から身体へ戻るループ

推進力・抵抗・横力・制動 → 実加速度・速度・位置 → 重心の応答・ZMPと荷重 → 胸・腰・脚IK → 実際に解いた骨点の重心高さ → 次の運動計算、というループにした。

- 平面移動は推進力／質量、速度依存抵抗、横方向のグリップ、制動力から積分。
- 重心の能動バランスは加速度と重力から平衡位置を求め、spring/damperで応答する。
- ZMP近似は重心位置から「重心高／重力×加速度」を引き、支持範囲・荷重比を求める。
- 姿勢側は固定した足・骨長・頭の世界向きを保ち、胸腰の傾斜・腰の水平移動・左右膝の違いを解く。
- 解いた身体の骨点重心を再測定し、実現した荷重proxy・目標との差・支持範囲外を表示する。
- 初回の重心高さ・支持幅をモデルごとに校正し、その後の高さ観測も時定数0.25秒で戻す。初期値configを上書きする方式ではない。

N02には時間sinの揺れを使わない。定速・加速度0の数値条件では勝手に周期揺れを作らず、停止後は釣り合いへ戻る。旧hover/boardの周期揺れは比較用の別モード。

## 制動の沈み込みを観察して修正

初期結合では固定足目標とCOMに合わせるため、片膝が120度超まで曲がった。COMの一律高さ0.9mと身体側の高さの不一致、低い脚の希望に腰全体を合わせる方式が原因だった。

初期の重心高を実姿勢・靴底から校正し、デモの推進を名目2.2m/s²、制動を名目3m/s²へ調整した。ただし実加速度には抵抗も加わるため、制動の実測は約-3.4m/s²などになる。

腰高さを左右の希望の平均で選び、この姿勢の表現方針として膝上限100度と伸び切り回避を加えた。水平の重心目標と競合する場合は移動量を減らし、重心残差・支持域外を表示する。足を動かして達成済みに見せることはしない。

| 実VRMの制動 | 初期結合 | 最終版 |
|---|---|---|
| A01の左右膝 | 約115.8 / 74.2度 | 約95.3 / 53.3度 |
| A03の左右膝 | 約120.3 / 73.6度 | 約97.9 / 52.4度 |
| 見え方 | 腰が大きく下がり、空気椅子の印象 | 深い沈み込みが減り、左右で受ける形へ改善 |
| 首の残りyaw | 約8度 | 約8度を維持 |
| 足目標 | 固定、ほぼ0mm差 | 固定、ほぼ0mm差を維持 |

最終版のCOM水平目標差は制動時A01約0.010mm、A03約0.020mm。荷重proxyと要求比には約2ポイントの差が残る。数値差が小さくても、全身の自然さ・服・髪・実際の接触力まで合格にしたわけではない。

## 今回の到達点

力・移動と、近似した重心・荷重およびIK姿勢を連動する縮約モデルの試作。N02で首へのねじれ集中を減らし、足を固定したまま胸・腰・膝が入力に応じて変わることを、実VRMの画像と数値で確認した。

全身の剛体・関節慣性・筋力、実足裏の摩擦や圧力、接触力の同時解決、地形衝突・転倒、雲の上下動は未実装。骨点の重みや足矩形は近似。衣服・髪のspring、VR一人称・実XRift・Quest・他者同期も未検証。U02は前段階の肩車試作のまま。

次は目標とする乗り味の強弱を選び、動いている最中の肩・腕・骨盤の反応や、体格／衣服ごとの見え方を調整する。ここでの数値をそのまま全アバター共通の規格へ固定しない。
