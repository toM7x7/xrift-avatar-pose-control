# N02：傾く筋斗雲と胸・腰・脚の追従

2026-10-25。上昇・下降のpitch、旋回のbankを雲へ加え、足裏・胸・腰・脚が追従するローカル実験を実装した。通常飛行は頭の入力世界向きを保つ。宙返り・背面飛行は今回含まない。

## 試し方

`npm run dev` → http://127.0.0.1:5228/ 。N02・「足場へ踏ん張る」を選び、手元のVRMを読み込む。

- 「上昇・下降・旋回で雲を傾ける」は既定ON。切替は停止・初期化して比較する。
- 「上昇→左右旋回→下降→停止を試す」で約14秒の連続コースを再生する。
- 手動の上昇・下降・前進・左右も併用できる。「全方向を制動」でその場に減速停止。
- 一時停止し、正面・横・斜めで脚と足裏、胸腰と頭の関係を見る。OFFは従来の水平足場の比較。

デモの傾斜上限はpitch±12度・bank±18度、pitch／rollの速度上限は各0.7rad/s。上限へ常時固定する設定ではなく、速度・加速度から目標を作って減衰付きで追従する。今回の入力ではpitch約±12度、bank約±3〜4度だった。値は表現の初期設定であり人体の共通規格ではない。

## 実装したループ

1. 従来の3軸推進・抵抗・制動で、位置・速度・実加速度を計算する。
2. 上下の進路と加速度からpitch、旋回の横加速度からbankを求める。真上・真下でもyawは保持する。
3. `QyawY × Qx(-pitch) × Qz(-roll)` の世界quaternionを作る。公開pitchの正は鼻上げ、rollの正は右bank。
4. `aWorld - gWorld` を同じ足場の法線・接線へ射影し、荷重代理・COM・ZMP・圧縮へ渡す。
5. 足首目標を雲の座標から世界へ運び、支持面の座標で身体を解く。頭の世界向きを保ち、足裏も面法線へ合わせる。
6. 骨と頭・足・腕・COM・ZMP・支持域の出力を世界へ戻し、足裏とCOM高を再観測する。

足場の傾斜は支持姿勢を決める。雲の移動を別に二重計算しない。傾斜ON/OFFへ同じ入力を与えた位置・速度・headingが一致することを数値試験で確認した。

## 足場・身体・頭

雲の回転中心は、初回に校正した左右足首の中心から靴底厚みを法線方向へ引いた接触面中心。足目標は保存したローカル座標から運ぶ。身体の解に雲を追従させる方式へ戻していない。初期yawが0以外でも中心を保つよう、ローカルの原点と初期世界原点を区別する。

支持面座標では膝と腰高さを解き、胸・腰を重力upへ部分的に補正する。腰30%・胸65%・首85%の補正を表現方針として比較開始した。既存の加速度leanを一律に弱めず、足場のtilt成分へ補正を限定している。頭と追跡手は入力の世界回転を保持する。足・骨長・膝の表現上限100度を守れない場合は誤差や制限理由を返す。

`supportFrame.position/quaternion` を新しい姿勢入力に追加。省略時は従来の水平経路を使う。`ride-dynamics` の `attitudeEnabled` も既定falseで、デモが明示的にtrueにする。旧forward/lateralAccelerationはyaw水平の実加速度を維持し、新tangentForward/tangentLateralAccelerationを支持面の需要として渡す。

COM高は `dot(COM - planeOrigin, normal)`。靴底診断も同じ法線へ描画頂点を射影する。世界minYを靴底厚みとして再校正しない。`upright` は従来どおり身体の世界up成分、`uprightSupport` は支持法線成分として分けた。

足の高低差を左右脚が受け、胸腰と頭の間に回転の分担ができた。最大膝は約93度で、既存の100度方針を超えていない。停止後は傾斜と身体が基準へ戻る。

頭の入力回転に対する差は約0.0000025度以下。首の全回転差は今回約8.6〜9.7度で、首だけへ90度を集中させる状態はない。モデル自身の静止時の頭upはA01約0.99698、A03約0.99740で、世界upと約4度の基準差があった。実VRMはこの静止基準との変化と入力Q誤差を判定し、雲の傾きを頭へ加えていない。自作骨格のneutral頭upは1を確認した。

足首目標・骨長の差は1mm未満。法線方向で測った足weight頂点の最小gapは最大A01約0.011mm、A03約0.0011mm。足裏normalのbind代理も面へ一致した。ただし、最小頂点の距離や骨軸の一致を、靴底全面の接触力・踵とつま先の精密なフィットの証明にはしない。

独立担当がON/OFF96条件を集計し、ON10枚を目視。靴底が傾斜面へ沿うこと、胸腰脚の釣り合い、顔が雲と一緒に倒れないことを確認。大きい浮きや貫通、空気椅子状の過沈下は見られなかった。格好よさ・機敏さ・腕の演技の調整は継続する。

## 今回の範囲と残る実験

傾斜と荷重は縮約モデル＋能動姿勢＋IK。荷重は足場原点の並進加速度を面へ射影した代理で、回転に伴う乗り手位置の角加速度・向心加速度はまだ含まない（`rotationalPointAccelerationIncluded=false`）。足首の解剖学的可動域、接触摩擦、関節トルク、全身剛体、転倒は完成していない。

カメラ追従はデモの任意の平行移動だけで、雲のpitch／bankをカメラへ渡さない。支持優先では頭位置が動くため、今回の成功はVR追跡の両立を示さない。実XRift・Quest・他者同期、宙返り・背面飛行、衝突は未確認／未実装。

次は通常範囲の乗り味と足首・衣服の余裕を広げ、回転点の加速度を加えた時も同じ姿勢が成立するか比較する。既存アイテムへの変更・アップロード・公開は行っていない。
