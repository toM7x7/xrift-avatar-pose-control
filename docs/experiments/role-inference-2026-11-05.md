- 実行環境: ローカル自作骨格（合成骨格・fixture）／ローカル実VRM（A01〜A03、ファイル選択と同じ手元の vrm/）。PC XRift は同じ所有者の筋斗雲アイテム（下記）で配布済みだが観察は未完、Quest・他者視点は未確認。
- avatar_id・VRM世代: A01〜A03 は全て VRM0（[実VRM記録](real-vrm-2026-10-25.md)と同じID）。合成骨格は Unity/VRM・VRoid・Mixamo・VRChat/Cats・Unreal・Rigify・3ds Max Biped・Character Creator・DAZ・MMD の名前と階層、名前なし、左右の印だけ。
- ride／表示物: 姿勢は N02 1.0.0 のまま（profile・タグ・採用再現は不変）。推定は呼んだときだけ動く別の入口。
- 再現手順: `npm test`（`tests/role-inference.test.mjs`）、手元の VRM は `node scripts/check-role-inference-vrms.mjs`（私有の結果は local-assets/、画面には匿名ID）。

## 背景

`inspectHumanoidRigs` は英語の別名表（`roleOf`）だけで 14 の役割を決める。名前が合わないアバターは安全側で当てない。筋斗雲アイテムの実機で、どの名前が合わないかを見る診断を入れた後、ユーザーから「実機の結果を待たずに、骨格の形から役割を推定する仕組みを作って。名前の対応表と組み合わせ、怪しいときは今まで通り当てない」と依頼があった。

同じ所有者の XRift 作業領域の `items/nimbus-cloud`（筋斗雲アイテム）で 2026-10-27 に作って検証し、アイテムの version 6 として XRift へアップロード済み。この記録は、その推定をこのリポジトリへ移したもの。アイテムは N02 のタグを固定して読んでいるため、ここへの追加はアイテムの挙動を変えない。

推定の中身:

- **名前**: 語の表（upperleg/upleg/thigh、lowerleg/calf/shin/knee、foot/ankle、upperarm/arm/shldr、lowerarm/forearm/elbow、hand/wrist、hips/hip/pelvis、head、neck、spine、chest、MMD の 足/ひざ/足首/腕/ひじ/手首/頭/首/上半身）。左右は L/R・Left/Right・左/右。twist・roll・end・IK・D などの付いた骨は除外。「leg」は Mixamo なら下腿、VRChat/Cats なら太ももなので両方で読み、矛盾しない方。
- **形**: 左右対称に下へ伸びる2本（脚）と、その上で左右対称に分かれる2本（腕）と、そこから上へ伸びる1本（首と頭）。腰は脚と腕の分かれ目の共通の親。股・膝・足首は太もも ≒ すねとつま先への曲がり、肩・肘・手首は上腕 ≒ 前腕と指の分かれ目（短い枝3本以上）、鎖骨は除外、頭は首から上で最も重い骨。
- **左右**: 名前の印・つま先の向き・足の頂点の重心。右手系で 左 = 上 × 前。手がかりが無い・食い違うなら決めない（VRM0 のバインドは -Z 向き、VRM1 は +Z 向きなので、座標の符号では決めない）。
- **組み合わせ**: 名前と形が別の腕・脚・頭を指す → 当てない。区切りの位置の違いは名前を優先、spine/chest/neck の食い違いは名前側を捨てる。最後に親子の順・脚が腰から下・肩が腰と頭の間・左右の腕と脚が同じ側・左右の長さ ±15%・比 0.5〜2・足の向きと左右の一致・頭に形があることを検査し、通らなければ当てない。

## 結果

| 確認対象 | 結果 |
|---|---|
| 合成骨格 10 流派＋名前なし＋左右の印だけ × ±Z × T/A | 全て 14 役割が正解と一致 |
| 長いスカート・床まで届くツインテール・胸の翼（指あり）・名前なしの翼 | 一致 |
| 床まで届くリボン、指のない腕＋マント／翼 | 決めるなら正解、僅差なら当てない（実際は前者が一致、後二つは当てない） |
| 寝た姿勢のバインド、100 倍の縮尺 | 一致 |
| 当てないもの: 四つ足・左右の名前が逆・腕だけ左右の名前が逆・名前もつま先も足の形も無い・14 本未満 | 全て当てず、理由を返す |
| fixture の名前を Cats／Unreal／MMD／意味なしへ付け替え | `inspectHumanoidRigs` は読めず、推定は元の骨へ戻し、N02 の姿勢は元の名前と 1e-9m 以内で一致。左右逆の名前は当てない |

## 限界・未確認

- バインド時が T/A ポーズであることを前提にした比と向きの検査。崩れたバインドは当てない側に倒れる。
- MMD でメッシュが足D などにだけ重みを持つ骨格は、役割が正しくても FK の足を動かしても形が動かない可能性（未確認）。
- 指のない腕と、同じくらいの長さの左右対称の枝（翼・マント）が同じ所から出ていると決めない。
- A02 は脚の形が入力に無いので、足裏の確認対象外のまま（役割の一致だけを確認）。
- 実XRift: 筋斗雲アイテム version 6 で配布済みだが、実機の観察（推定で乗れたアバターの姿勢）は未完。Quest・他者視点は未確認。
