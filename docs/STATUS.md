# 初期版とN02/U02実験の状態

## 2026-10-25：他姿勢の大量SIMと18候補

`/patterns.html`へ7系統・18候補の比較画面を追加。椅子座り・またがり・横座りは新しい腰支持IK、立つ・N02・伏せる・肩車は既存コアと実験adapterを使用する。通常324／境界込み540の意味のある条件を生成し、実VRM3体では全条件screen後に代表を24フレーム再確認する。自作3体格は別に972条件・23,328フレームをCPU再現する。

採用profileはN02通常飛行1.0.0のまま。新候補は未採用で、数値・可視形状・接触・見た目の判定を分ける。[実験結果と未達](experiments/pose-patterns-2026-10-25.md)を参照。

## 2026-10-25：N02 通常飛行1.0.0を採用

ユーザーが現仕様を採用。[再現仕様](specs/N02_NORMAL_FLIGHT_V1.md)・[JSON正本](../specs/n02-normal-flight.v1.json)・[モデル接続への引継ぎ](handoff/NIMBUS_MODEL_INTEGRATION.md)を追加。デモの設定と14秒コースを共有profileへ接続し、`npm run replay:n02`で私有VRM不要の1740フレーム／16checkpointを再現する。採用タグは `n02-normal-flight-v1.0.0`、npm公開とは別。

共有化後の119テスト・型・build、CPU replayと同環境での再実行数値一致、デモの傾斜14条件も成功。結果は[引継ぎ資料](handoff/NIMBUS_MODEL_INTEGRATION.md)末尾へ集約。実VRM96枚は前回の採用根拠として保持し、共有化を新しい実VRM試験と扱わない。実XRift／Quest／他者同期は引き続き未確認。以下は採用前の履歴。

## 2026-10-25：傾く雲と全身追従

[傾斜の実験記録](experiments/n02-tilted-ride-2026-10-25.md)。上昇下降pitch・旋回bankを雲へ追加。傾いた支持座標で足裏・胸腰脚を解き、頭の入力世界向きを維持する。約14秒の連続コースと傾斜ON/OFF比較を用意。114テスト・型・build、傾斜14条件、従来14／10／22の回帰が成功。実VRM2体・ON48/OFF48の96枚をモデル診断まで照合し、独立目視10枚を確認しました。

通常デモ上限pitch12/bank18度、観測では上下約12度／旋回約3〜4度。最大膝約93度で表現上限内。靴底の判定は支持法線方向。回転点の加速度・全身接触力・実XRift／Quest／他者・宙返りは未対応で、以下は各時点の履歴です。

## 2026-10-25：上下移動と胸・腰・脚の連動

[上下の実験記録](experiments/n02-vertical-ride-2026-10-25.md)。上昇・下降・全方向制動と約9秒の再現コースを追加。加速度で変わる荷重から胸腰の屈伸・膝・腰高さが連動し、停止復帰。足場は水平＋yaw。95テスト・型・build、上下ブラウザ14条件、水平10／旧姿勢22の回帰が成功。実VRM2体×7状態×3視点＝42枚を確認。比較元のA03誤ラベル3枚は自作骨格だったため除外し、最終42枚はモデル診断まで照合しました。

低／負荷重時はZMP・荷重比をnull＋理由で出し、足を接続する魔法の状態を区別。bank・宙返り・実XRift・Quest・他者同期は未実装／未確認です。以下の「企画のみ」は企画作成時点の履歴です。

## 2026-10-25：N02の走行・全身バランス

首へ90度を集中させていた構えを、腰50度・胸20度・首残り約8度へ分散。足場を姿勢へ追従させる表示から、雲に固定した足目標へ身体を合わせる実験へ変更。推進・抵抗・横力・制動から移動を計算し、COM応答・近似荷重・胸腰膝と、解いた身体の高さfeedbackを連動しました。

- npm run verify成功：78件・型・build。走行10条件と旧頭優先22条件も成功。
- A01/A03の5状態×3方向＝30枚を初期結合／最終版で別保存。首約8度・固定足を保ち、制動の過大な沈み込みを改善。
- 近似運動／能動バランス＋IKの試作。全身剛体・接触力・摩擦・転倒・実XRift／Questは未確認・未実装の範囲として分けています。

最新は[走行ループの記録](experiments/n02-ride-loop-2026-10-25.md)。以下は各段階の履歴です。

## 2026-10-25：持込の実VRMと腕の再調整

3体のVRM0をローカル読込し、native／N02／U02の27条件を観測。向き、靴底候補、模擬着座、撮影範囲を修正しました。N02の腕はユーザーの批評を受けて、肩→肘→手先が外下へ流れる非対称な構えと掌下へ再調整。実VRMの腕を追加12条件で観察しました。

- A01/A03のN02は静止比較として成立。A01のU02も輪郭を確認。A03のU02は衣服・頭周りの干渉調整が残ります。
- A02は脚・足に追従する形状が入力にないため、足裏支持・可視すね保持の検証対象外です。
- 最終npm run verify成功（56件・型・ビルド）、既存自作骨格の22条件も回帰成功。
- 元VRM・実名対応・私有画像はGit対象外。実XRift／Quest／他者同期は引き続き未確認。

詳細は[実VRM記録](experiments/real-vrm-2026-10-25.md)と[腕の調整記録](experiments/n02-arm-refinement-2026-10-25.md)。以下の48件・実VRM未実施の記述は、その前段階の記録です。
