# ローカル参照用のVRM置き場

実験に使うVRMをこのフォルダへ置いてください。このREADME以外の内容はGitの対象外です。

例:

```text
vrm/
  README.md
  A01-standard.vrm   ← 基準となる標準体格
  A02-small.vrm      ← 頭上表示が前へずれた小型モデル
  A03-other.vrm      ← 別作者・別エクスポーターの比較用
```

名前は例なので、元のファイル名のままでも構いません。モデル本体・同梱テクスチャ・モデル別の私的メモはコミットされません。

1. `npm run dev` でデモを起動し、http://127.0.0.1:5228/ を開きます。
2. 「手元のVRMを読み込む」から、このフォルダに置いたファイルを選びます。複数選択すると、画面の一覧から切り替えられます。
3. N02／U02と観察方向を選びます。調整値と計測値は画面の「計測値」で確認し、比較条件は `docs/experiment-record-template.md` に記録できます。

フォルダに置いただけで自動読込する機能はありません。アバター本体はブラウザ内で処理し、GitHubへアップロードしません。ビルド用の `public/` 配下には置かないでください。
